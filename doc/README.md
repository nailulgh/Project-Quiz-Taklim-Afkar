## Quick Start untuk AI Agents

Jika kamu adalah AI coding agent yang baru bergabung ke proyek ini:

1. **Baca `claude.md` dulu** — ini adalah panduan operasional wajib
2. **Baca `srs.md` section 1–5** — pahami produk dan domain
3. **Baca `design.md` section 1–4** — pahami arsitektur
4. **Cek `todo.md`** — lihat task yang sedang dikerjakan
5. **Update `changelog.md`** setelah setiap task selesai
